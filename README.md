\## Запуск проекта



Для работы используются инструменты Poetry (менеджер зависимостей) и pytest (тестирование).



1\. \*\*Установить зависимости:\*\*

&#x20;  poetry install



2\. \*\*Запустить CLI-утилиту:\*\*

&#x20;  poetry run my-cli 5

&#x20;  (или poetry run python -m lab\_work\_8.cli 5)



3\. \*\*Запустить тесты:\*\*

&#x20;  poetry run pytest



4\. \*\*Запустить проверку стиля кода (flake8):\*\*

&#x20;  poetry run flake8 lab\_work\_8 tests
